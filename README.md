# Creative Skills

A collection of experiments by Arno Faure, exploring creative processes through AI, filmmaking, image and memory.

**Experimental draft.** The portable workflow has not yet been tested with an independent FLORA account or in FAUNA; model availability, pricing and results can vary.

## Skills

### [Fragments — Try to remember again](skills/fragments/SKILL.md)

An experiment around one fictionalized childhood memory. Each invocation attempts to find another fragment of the same moment, without explaining the whole story.

- **Status:** Draft; the portable workflow has not been tested with an independent FLORA account.
- **Output:** One still and a five-second video, subject to model availability and explicit cost approval.
- **Reference:** The image is included at `skills/fragments/assets/reference.png`.

Read the [Fragments notes](skills/fragments/README.md) before trying or sharing it.

## A note on using these skills

A skill is a set of instructions for an AI assistant, not an application or a guarantee of a particular result. FLORA MCP can make workspace skills available to connected agents; placing a file on GitHub does **not** automatically install it in FLORA or establish that FAUNA can run it. Each workflow needs its own test and instructions.
